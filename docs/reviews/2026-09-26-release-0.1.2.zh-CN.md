# MapDesign 0.1.2 发布准备验证

验证日期：2026-09-26。环境：macOS arm64、Node 24.19.0、pnpm 10.33.2。

## 修复内容

- 调整波兰语长度提示，消除旧品牌词守卫误报，保留守卫规则。
- 将发布工作流要求同步的 13 份 manifest 更新为 `0.1.2`，避免重复使用已发布的 `0.1.1`。
- 修复 macOS 安装版启动时读取开发目录 Dock 图标而退出的问题；安装版使用应用包图标。
- 预览等待从开始即启用已有的 50 ms 就绪检查。新增回归用例证明：未收到 `idle` 事件时，旧实现会超时，修复后可正常捕获预览。
- 纳入此前已审查的运行恢复、取消清理、工作区标签页和文档更新。

最初浏览器测试为 12 通过、1 失败：历史版本返回后预览过期。该流程单独重跑通过，随后补充上述缺失 `idle` 的确定性回归修复。浏览器测试使用隔离 daemon、真实浏览器和模拟 Agent 协议，不代表真实模型服务验收。

修复后的整组测试中历史版本流程通过；Oh My Pi 在并行构建期间超过状态断言的 10 秒上限，仍显示运行中。构建结束后保持源码和测试超时不变，连续两次复测通过（7.6 秒、6.9 秒）。并行负载是可能原因，未证明唯一根因；保留此稳定性观察，不将整组结果记为一次全绿。
