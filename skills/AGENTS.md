# Skills

`map-design` is the bundled MapDesign skill. It is staged by the daemon for project runs. Keep its instructions and references specific to map sources, projects, drafts, preview, validation, revisions, and local agent work.

User-installed skills are local runtime data, not source-catalog files.
`cartography-init`, `cartography-md`, and `data-profile` are bundled cartography skills. The init and profile packages include their runnable tools and tests; keep their documentation and entrypoints in sync.
